# DataBase.Me documentation

A free, open-source, local-first **lifetime information repository**: notes, documents, tables,
files and pictures in one vault on your own disk, shown as a document, an outline, a mind map, a
table or a gallery, mirrored as plain Markdown files, and never sent anywhere.
